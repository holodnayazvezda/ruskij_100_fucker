# ruskij_100_fucker

Скрипты для работы с тестами по русскому языку: получение ответов и заполнение заданий с использованием локального набора JSON. В репозитории сохранены ответы по типам заданий в каталоге `answers/`.

## Подготовка

```sh
python -m pip install -r requirements.txt
```

Настройте адрес теста и параметры HTTP-запросов в `config.py`. В `main.py` выберите номера заданий и режим: `GETTER` для получения ответов либо `SOLVER` для использования сохранённых данных. Затем запустите `python main.py`.

Основная логика находится в `core/`, классификация и подготовка данных — в `tasks_json_parsers/`. Режим `SOLVER` отправляет запросы к настроенному сервису; используйте его только для тестов, с которыми намерены работать. Формат заданий и сессия доступа должны соответствовать настройкам проекта.
